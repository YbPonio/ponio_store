# Obsidian

Summary: A local-first, markdown-based knowledge management tool that operates directly on plain text files. Serves as the recommended viewer and graph visualizer for the LLM Wiki pattern.

## Role in the LLM Wiki Architecture

- Acts as the human user interface and visual IDE while the LLM acts as the backend maintainer and programmer.
- Native wikilink support (`[[page]]`) allows navigation across entities, concepts, and sources.
- Graph View provides real-time visualization of interconnected clusters, orphan files, and central knowledge hubs.
- Extensible via ecosystem plugins such as Dataview (frontmatter queries), Marp (presentation generation), and Web Clipper.
